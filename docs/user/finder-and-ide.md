# Finder and IDE

Use the workspace switcher in the T3 Code header and choose **Finder & IDE** to browse and edit files in projects registered with your connected environments.

Choose a project, filter its files, and open a text file to edit it. Save with the Save button or `Cmd+S`/`Ctrl+S`. The toolbar can create files and folders, rename or move the selected file, and delete it after confirmation.

Finder operates inside registered project roots. It does not expose unrelated files from the host device. Files larger than 1 MB are available as read-only previews.
