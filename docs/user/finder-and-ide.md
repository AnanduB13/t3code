# Finder and IDE

Use the workspace switcher in the T3 Code header and choose **Finder & IDE** to browse and edit files on a connected environment. Finder opens at that device's Home folder. Use **Computer** to start at the filesystem root or a project shortcut to jump directly to a workspace.

Navigate with Back, Up, Home, or by double-clicking folders. Both list and icon views are available, along with per-folder search and a hidden-file toggle. Double-click a text file to edit it, then save with the Save button or `Cmd+S`/`Ctrl+S`. The toolbar can create files and folders, rename or move the selected item, and delete it after confirmation.

Finder uses the permissions of the T3 Code server process on that environment. Files larger than 1 MB are available as read-only previews.
