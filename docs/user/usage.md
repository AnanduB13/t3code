# Review usage

The Usage page combines Codex, Claude Code, and Grok Build activity from your connected
environments. It reads the providers' local session history and shows API-equivalent token cost,
cache savings, provider shares, and model breakdowns. Web and desktop also show processed tokens. Subscription billing is
separate from the raw token cost shown here.

Grok Build totals come from persisted session updates. Interactive turns that never wrote a
completed-turn record will not appear.

On web and desktop, use the **7 days**, **30 days**, **90 days**, and **All time** ranges to review
daily usage. Their cost and token toggles update both the headline and chart.
Web and desktop open **Limits** on your first visit and remember your last selected view.
The provider rows show session and weekly quota, account segments, and reset countdowns across
connected environments and configured account sources. Select an account segment to see its plan,
exact reset time, and any banked reset credits. **Use reset** asks for confirmation before spending
a credit. Older environments show the account windows they support.
Refreshing while Limits is open reloads account limits.
Mobile shows cost only, without raw token counts or a token toggle, and also offers **Past 24h**
with hourly detail. Refreshing rescans every connected environment.
